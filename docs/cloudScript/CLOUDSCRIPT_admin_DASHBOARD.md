# CLOUDSCRIPT ADMIN DASHBOARD

## 1. Mục đích

File này chỉ tập trung vào `admin.dashboard` trong cloud script.

> Lưu ý: `admin.dashboard` chỉ expose các hàm (`getAdminAccountList`, `getAdminAccountListAsync`, `getGameInformation`, `getGameInformationAsync`, `getGameList`, `getGameListAsync`, `getMasterGameSettings`, `getMasterGameSettingsAsync`, `getSecretInfoInformation`, `getSecretInfoInformationAsync`, `getSecretInfoInformationAsync`, `getSecretInfoList`, `getSecretInfoListAsync`, `getServerLog`, `getServerLogAsync`, `setGameInformation`, `setGameInformationAsync`, `getUsernameAdminAccount`, `getUsernameAdminAccountAsync`, `getAnalytics`, `getAnalyticsAsync`, `resetStatisticsLeaderboard`, `resetStatisticsLeaderboardAsync`, `getBackupStatisticsLeaderboardVersion`, `getBackupStatisticsLeaderboardVersionAsync`, `getServerGameData`, `getServerGameDataAsync`, `deleteInDatabase`, `deleteInDatabaseAsync`).

Mapping chính:

- `admin.dashboard` → `GNNetwork.dashboard`

## 2. Ví dụ sử dụng

```ts
const assertResponseOk = (response: CustomOperationResponse, actionName: string): void => {
    if (response.hasReturnCodeError()) throw new Error(actionName + " return-code error: " + (response.debugMessage ?? response.toString()));
    if (response.errorCode !== ErrorCode.Ok) throw new Error(actionName + " business error: " + response.errorCode);
};

// Đọc analytics cơ bản
handlers["getLeanAnalytics"] = async (args: any, context, log) => {
    const requestData = new DashboardModels.GetAnalyticsRequestData();
    requestData.country = true;
    requestData.requestComplete = true;

    const response = await admin.dashboard.getAnalyticsAsync(requestData);
    assertResponseOk(response, "getAnalyticsAsync");

    return response.responseData;
};

// Hard delete một record trong DB — dùng thận trọng, không thể hoàn tác
handlers["deleteRecord"] = async (args: any, context, log) => {
    if (typeof args?.itemId !== "string" || args.itemId.length === 0) throw new Error("itemId is required");

    const requestData = new DashboardModels.DeleteInDatabaseRequestData();
    requestData.gameId = gameId;
    requestData.type = OwnerType.Inventory;
    requestData.id = args.itemId;
    requestData.log = "manual delete from cloudscript, requestedBy=" + context.userId;

    const response = await admin.dashboard.deleteInDatabaseAsync(requestData);
    assertResponseOk(response, "deleteInDatabaseAsync");

    return { deleted: true, id: args.itemId };
};
```
